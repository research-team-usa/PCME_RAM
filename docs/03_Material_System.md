# Chemical Material System

- **Ru Top-Electrode:** $20\,nm$ (Adhesion promoter and electrical contact)
- **CoFe2O4:** $15\,nm$ (Magnetostrictive layer, free of rare-earth elements)
- **BaTiO3:** $50\,nm$ (Piezoelectric actuator, lead-free)
- **SrRuO3:** $30\,nm$ (Bottom-Electrode / Buffer layer)
- **AlN:** $80\,nm$ (Acoustic transducer, MEMS-compatible)
- **Si(100):** Highly doped silicon substrate
